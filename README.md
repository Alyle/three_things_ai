# 三件事AI助手

一个帮助你管理重要目标的应用。每个时间周期（今日/本周/本月/本季/今年）最多可以设定三个最重要的目标。

## 当前功能

- 目标管理
  - 支持五个时间周期：今日、本周、本月、本季、今年
  - 每个周期最多添加三个重要目标
  - 支持目标的添加、编辑、删除和完成状态更新
  - 优雅的滑动删除动画
  - 支持撤销删除操作
  - 即时的操作反馈提示

- AI助手功能
  - 实时对话界面
  - 消息时间戳显示
  - 优雅的消息加载动画
  - 自动滚动到最新消息

- 用户体验
  - Material Design 3 风格
  - 统一的主题系统
  - 响应式布局
  - 中文字体优化

## 技术特点

- 使用 GetX 进行状态管理
- 采用 MVC 架构模式
- 跨平台支持（移动端）
- 响应式编程
- Material Design 3
- 中文字体优化

## 开发环境

- Flutter 版本: 3.19.0
- Dart 版本: 3.3.0
- GetX 版本: 4.6.6

## 项目结构

```
lib/
├── core/           # 核心功能
│   ├── constants/  # 常量定义
│   ├── theme/      # 主题相关
│   └── utils/      # 工具类
├── controllers/    # 控制器
├── models/         # 数据模型
├── services/       # 服务层
├── views/          # 视图层
│   ├── pages/      # 页面
│   │   ├── home/   # 主页相关
│   │   └── chat/   # 聊天相关
│   └── widgets/    # 可复用组件
└── main.dart       # 入口文件
```

## 如何运行

1. 确保已安装 Flutter 开发环境
2. 克隆项目到本地
3. 运行以下命令：

```bash
flutter pub get
flutter run
```

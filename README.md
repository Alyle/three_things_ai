# 三件事AI助手

一个帮助你管理重要目标的应用。每个时间周期（今日/本周/本月/本季/今年）最多可以设定三个最重要的目标。

## 当前功能

- 目标管理
  - 支持五个时间周期：今日、本周、本月、本季、今年
  - 每个周期最多添加三个重要目标
  - 支持目标的添加、编辑、删除和完成状态更新
  - 优雅的滑动删除动画
  - 支持撤销删除操作
  - 即时的操作反馈提示

## 开发环境

- Flutter 版本: 3.16.0
- Dart 版本: 3.2.0

## 如何运行

1. 确保已安装 Flutter 开发环境
2. 克隆项目到本地
3. 运行以下命令：

```bash
flutter pub get
flutter run
```
